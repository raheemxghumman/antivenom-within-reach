# Data

`sanghar_osm.json` is an extract of OpenStreetMap data (health facilities and `place=*`
settlements in the bounding box 25.70–26.40 N, 68.70–69.50 E, Sanghar district, Sindh, Pakistan),
fetched with the Overpass API on 12 November 2026.
